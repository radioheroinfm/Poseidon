## Критическое открытие

**API в renderer называется `window.hermesDesktop`, а не `window.electronAPI`.**

```ts
contextBridge.exposeInMainWorld('hermesDesktop', {
  windowControls: { minimize, toggleMaximize, close, custom },
  getGatewayWsUrl: ...,
  // ... очень большой API
})
```

Наш `desktop-bridge`, который ставит `window.electronAPI`, **не является 1:1** с текущим апстримом.  
Это была рабочая гипотеза ранней фазы; теперь она опровергнута чтением preload.

## Готовность backend

Hermes Desktop ждёт в stdout строку вида:

```
HERMES_BACKEND_READY port=<N>
```

или legacy:

```
HERMES_DASHBOARD_READY port=<N>
```

Cold start может занимать **30–60 секунд**.  
Порт **не зафиксирован** как 8642 — он анонсируется процессом.

Следствие для `GatewayManager`:
- Discover только по фиксированному 8642 — неполная эвристика
- Нужно читать stdout child-процесса и парсить READY-строку
- Таймаут ожидания должен быть порядка десятков секунд, не 3с

## Объём preload

`preload.ts` — большой (760+ строк). Полный паритет `hermesDesktop` — это Эпоха 3+, не Эпоха 2.  
Для Эпохи 2 достаточно:
1. Честно переименовать/добавить `window.hermesDesktop` как основной контракт
2. Оставить `electronAPI` как deprecated alias только если где-то ещё используется в наших моках
3. Реализовать минимальный subset: windowControls + gateway connection helpers
