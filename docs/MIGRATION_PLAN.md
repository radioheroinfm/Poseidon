## Эпохи 4+ — Постепенный перенос на Rust (цель Толяна)

Порядок (гипотеза, уточняется после инвентаризации):
1. Управление процессом шлюза (уже начато)
2. Хранилище сессий (SQLite/FTS5) — сначала read-only
3. Диспетчер инструментов
4. Адаптеры платформ и сборка промптов — в конце (часто меняются в апстриме)

Правило: компонент не заменяется, пока харнесс паритета не зелёный.
