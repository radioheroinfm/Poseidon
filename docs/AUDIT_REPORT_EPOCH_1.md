## 2. Разбор найденных дефектов и рисков

### 🔴 Баг №1: Мёртвая блокировка (Deadlock) в `Drop` для `GatewayManager` (`src-tauri/src/gateway.rs`)
* **Место в коде**:
  ```rust
  impl Drop for GatewayManager {
      fn drop(&mut self) {
          if let Ok(owned) = self.owned_by_us.lock() {
              if *owned {
                  let _ = self.stop(); // <--- DEADLOCK!
              }
          }
      }
  }
  ```
* **Механика**: Внутри блока `if let Ok(owned) = self.owned_by_us.lock()` guard `owned` удерживается живым в области видимости. Внутри вызывается `self.stop()`, который первым же действием делает `let mut owned_guard = self.owned_by_us.lock()`. Мьютексы в Rust (`std::sync::Mutex`) нереентрантны. Поток пытается повторно захватить собственный мьютекс и засыпает навсегда.
* **Следствие**: При выходе из приложения или падении процесса процесс виснет наглухо и не завершается.
* **Исправление Жени**: Скопировать булево значение и немедленно освободить блокировку до вызова `self.stop()`:
  ```rust
  impl Drop for GatewayManager {
      fn drop(&mut self) {
          let should_stop = self.owned_by_us.lock().map(|g| *g).unwrap_or(false);
          if should_stop {
              info!("GatewayManager dropped — stopping owned gateway");
              let _ = self.stop();
          }
      }
  }
  ```

### 🔴 Баг №2: Блокировка WebSocket/HTTP политикой CSP (`src-tauri/tauri.conf.json`)
* **Место в коде**:
  ```json
  "connect-src 'self' ipc: http://ipc.localhost"
  ```
* **Механика**: Hermes Gateway работает как локальный сервер на порту 8642 (`ws://127.0.0.1:8642` и `http://127.0.0.1:8642`). Текущая политика CSP запрещает любые сетевые соединения наружу от WebView, кроме IPC самого Tauri.
* **Следствие**: При попытке React-рендерера открыть сессию чата или отправить команду шлюзу WebView выбросит ошибку безопасности: `Refused to connect to 'ws://127.0.0.1:8642' because it violates CSP`.
* **Исправление Жени**: Расширить директиву `connect-src`:
  ```
  connect-src 'self' ipc: http://ipc.localhost ws://127.0.0.1:* http://127.0.0.1:* ws://localhost:* http://localhost:*
  ```

### 🟡 Замечание №3: Рассинхрон команд диалогов (`desktop-bridge` vs `bridge.rs`)
* В `src/desktop-bridge/index.ts` объявлены вызовы:
  `invoke('show_open_dialog', { options })` и `invoke('show_save_dialog', { options })`.
* Но в Rust (`src-tauri/src/bridge.rs`) эти команды отсутствовали в `tauri::generate_handler!`.
* **Исправление Жени**: Добавлены безопасные заглушки `show_open_dialog` и `show_save_dialog` в Rust, чтобы при клике в интерфейсе приложение не падало с `Command not found`, пока мы не подключим `tauri-plugin-dialog`.

---

### 🟡 Замечание №4: События изменения состояния окна (`onWindowStateChange`)
* В `src/desktop-bridge/index.ts` метод `onWindowStateChange` возвращает пустую функцию `() => {}`.
* В интерфейсе Hermes кастомный тайтлбар должен менять иконку «Развернуть» на «Восстановить» при двойном клике по шапке или при системном снаппинге окна. Без событий иконка будет рассинхронизирована.
* **Рекомендация на Эпоху 2**: подключить слушатель событий `tauri::WindowEvent::Resized`.
